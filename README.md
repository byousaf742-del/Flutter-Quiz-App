# Flutter Quiz App

A simple and interactive quiz application developed using **Flutter** and **Dart**.

## Features

- Welcome screen with name entry
- Subject selection
- Multiple-choice quiz questions
- Instant feedback for correct and incorrect answers
- Automatic score calculation
- Results screen with score percentage and answer summary
- Option to start a new quiz

## Technologies Used

- Flutter
- Dart
- Material Design

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/byousaf742-del/flutter-quiz-app.git
   ```
2. Open the project folder:
   ```bash
   cd flutter-quiz-app
   ```
3. Install dependencies:
   ```bash
   flutter pub get
   ```
4. Run the app:
   ```bash
   flutter run
   ```
